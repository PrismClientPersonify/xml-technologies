# Контрольная точка по дисциплине «XML технологии»

Сессия. Пересдача задания «Претендуем на звание Мастера XSLT».

## Задание

Выполнено преобразование исходного XML-документа в HTML с помощью XSLT.

Требовалось:

- сгруппировать компании по городам;
- сгруппировать товары по компаниям;
- учитывать, что компании с одинаковым названием в разных городах являются разными организациями;
- использовать ключи для группировки данных.

## Файлы проекта

- `data.xml` — исходный XML-документ;
- `transform.xsl` — XSLT-преобразование;
- `result.html` — результат преобразования;
- `index.html` — копия результата для GitHub Pages;
- `transform.ps1` — запуск преобразования;
- `test.ps1` — автоматические проверки;
- `tests/expected.html` — исходный образец результата из задания.

## Решение

В XSLT 1.0 используется группировка Мюнха (Muenchian grouping) и два ключа:

```xml
<xsl:key name="items-by-city" match="item" use="@city"/>
<xsl:key name="items-by-city-org" match="item"
  use="concat(string-length(@city), ':', @city, '|', @org)"/>
```

Ключ компании состоит из города и названия организации. Поэтому московская и петербургская `ООО Светлана` обрабатываются отдельно.

Префикс с длиной города исключает совпадение составных ключей, даже если в названиях встречается символ `|`. Через `generate-id()` выбирается первый элемент каждой группы, а `key()` возвращает все её товары.

Города и компании выводятся в порядке первого появления в XML, товары — по алфавиту. «Всего товаров» означает количество строк `item`, как в образце, а не сумму атрибутов `value`. Название `Футблока` сохранено без исправлений из исходного задания.

Результат: 2 города, по 3 компании в каждом, по 7 товарных строк на город. В каждой из двух организаций `ООО Светлана` выводится по 2 товара. Структура и текст `body` совпадают с образцом; дополнительно оформлены шрифты и заголовки.

## Локальный запуск

Откройте `result.html` или `index.html` в браузере. Это уже сформированный HTML — поддержка XSLT в браузере не требуется.

Повторное преобразование и проверки через PowerShell 7, без установки дополнительных библиотек:

```powershell
pwsh -File ./transform.ps1
Copy-Item ./result.html ./index.html -Force
pwsh -File ./test.ps1
```

Для другого XML:

```powershell
pwsh -File ./transform.ps1 -InputPath ./other.xml -OutputPath ./other.html
```

Сам файл `transform.xsl` можно использовать с процессором XSLT 1.0 без PowerShell.

Проверки сравнивают результат с образцом, проверяют изоляцию одноимённых компаний, несмежные записи, сортировку товаров, специальные символы, пустой XML и соответствие HTML-файлов текущему преобразованию.
